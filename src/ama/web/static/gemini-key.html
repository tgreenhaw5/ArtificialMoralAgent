Get a free Gemini API key

ArtificialMoralAgent uses Google's Gemini Flash-Lite by default. A free key takes about two minutes and no credit card.

  1. Open aistudio.google.com/apikey and sign in with a Google account.
  2. The first time, accept the Gemini API terms. The marketing checkbox is optional.
  3. Click Create API key. If asked, choose Create API key in new project.
  4. Copy the key straight away; it is shown in full only once. Keep it private, like a password.
  5. On the computer running ArtificialMoralAgent, run ama init and paste the key when asked. (Or add GEMINI_API_KEY=your-key to ~/.ama/.env.) Then restart ama serve.
  6. Check it with ama doctor: the model reachable and embeddings lines should say PASS.
Privacy on the free tier: Google may use data sent through free-tier keys to improve its products. Avoid putting confidential or identifying details into dilemmas while using a free key, or use a paid key, or the local preset with Ollama, where nothing leaves your computer. Free-tier use is rate-limited, not billed.
